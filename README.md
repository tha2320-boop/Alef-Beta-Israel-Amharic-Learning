# אלף-ביתא ישראל - למידת אמהרית

כלי לתרגול אמהרית לדוברי עברית: מסלול של יחידות ונושאים, מסכי לימוד לפני כל תרגול, לוח פידל עם תרגול כתיבה, וחזרה מרווחת.
הכתיב הלטיני הוא הסימון של טבלאות הפידל של המורה (ä, e, ï, š, č, ž, ň, k', t').

## מה יש בריפו

| תיקייה | מה בה |
|---|---|
| `site/index.html` | הכלי המלא |
| `site/letters.html` | לשונית האותיות בלבד, בלי הקלטות |
| `site/js/app.js` | הקוד. משותף לשני הדפים |
| `site/data/lessons.js` | הנושאים מהשיעורים |
| `site/data/vocab.js` | נושאי אוצר המילים |
| `site/data/tips.js` | הסברי הדקדוק |
| `site/audio/` | חמש ההקלטות של המורה |
| `tests/` | הבדיקות, ורשימת מפתחות ההתקדמות (`keys.json`) |
| `tools/build-single.mjs` | אורז דף לקובץ HTML אחד, לגרסה שרצה ב-Claude |

## איך זה עולה לאוויר

כל דחיפה ל-`main` מריצה את הבדיקות, ואם הן עוברות, התיקייה `site/` מתפרסמת ב-GitHub Pages.
הגדרה חד-פעמית: **Settings > Pages > Source: GitHub Actions**.
התוצאה נראית בלשונית **Actions**. ✗ אדום פירושו שבדיקה נכשלה, והאתר הקודם נשאר באוויר.

## הרצה מקומית

```
npm install
npx playwright install chromium
npm test
```

את הדפים אפשר פשוט לפתוח בדפדפן מתוך `site/`.

## שינוי כרטיס

ההתקדמות נשמרת לפי מפתח של כל כרטיס, שנגזר מהכתיב שהיה לו כשנוסף. לכן:

- **מוסיפים** כרטיס חדש רק בסוף נושא, כדי לא להזיז את הסימונים בדף הבדיקה של המורה.
- **משנים כתיב לטיני** של כרטיס מהשיעורים: מוסיפים ל-`ALEF.KEY_OF` שורה של הכתיב החדש מול הכתיב הישן.
- **משנים פידל** של כרטיס אוצר מילים: שמים את הפידל הישן בשדה השלישי של הכרטיס.
- **נושא חדש** מקבל מקום ביחידה ברשימה `UNITS` ב-`js/app.js`.

הבדיקה "no card lost its progress key" נכשלת אם כרטיס איבד את המפתח שלו.
אחרי הוספת כרטיסים מריצים `npm run test:update-keys`, כדי ש-`keys.json` יכלול גם אותם.

## הגרסה ב-Claude

`npm run build:single` כותב את `dist/index.html`, קובץ אחד עם ההקלטות בתוכו, שאפשר לפרסם ב-Claude.
ההתקדמות שם נשמרת בחשבון. באתר היא נשמרת בדפדפן בלבד.
